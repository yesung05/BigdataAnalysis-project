## 1. 뺑뺑이(2차 이송) 분석

### 1-1. 연도별 발생률 (`bbang_01_yearly_rate.png`)

```
[A] 구급출동 샘플 (20,000행/년 × 6년 = 120,000행)
  └─ 파생컬럼 생성
       has_trans2  = TRANS2_RSN.notna()      ← 2차 거부이유 기재 여부
       has_trans3  = TRANS3_RSN.notna()      ← 3차 거부이유 기재 여부
  └─ groupby(_year)
       → 연도별 2차이송건수 / 전체건수 = 발생률(%)
```

| 컬럼 | 역할 |
|------|------|
| `TRANS2_RSN` | 2차 이송 거부 이유 (기재 시 뺑뺑이로 정의) |
| `_year` | 로드 시 부여한 연도 컬럼 |

---

### 1-2. 서울 자치구별 발생률 (`bbang_02_district_rate.png`)

```
[A] 구급출동 샘플 (120,000행)
  └─ 파생컬럼: has_trans2 = TRANS2_RSN.notna()
  └─ groupby(GRNDS_SGG_NM)
       → 자치구별 2차이송건수 / 전체건수 = 발생률(%)
       필터: 샘플 200건 이상인 자치구만
```

> **주의**: `GRNDS_CTPV_NM`(시도) 기준으로 분석하면 데이터가 서울 99%+로 편향되어  
> 무의미하므로 `GRNDS_SGG_NM`(시군구) 레벨로 세분화.

---

### 1-3. 거부 이유 분류 (`bbang_03_reason.png`)

```
[A] 구급출동 샘플
  └─ 필터: has_trans2 == True (TRANS2_RSN 기재된 행만)
  └─ 파생컬럼: trans2_reason_cat = 키워드 매핑(_categorize_reason)
       "응급실"       → 응급실 포화
       "입원실","중환자실","병상" → 병상 부족
       "전문의","진료","부재" → 진료 불가
       "거리","접근"  → 거리·접근성
       그 외          → 기타
  └─ value_counts(trans2_reason_cat)
```

> 실제 `TRANS2_RSN` 상위 값(50k 샘플): 응급실(55), 전문의부재(9), 기타(8), 입원실(3), 중환자실(3)

---

### 1-4. 추가 이동 거리 분포 (`bbang_04_extra_distance.png`)

```
[A] 구급출동 샘플
  └─ 필터: has_trans2 == True
  └─ extra_dist = clip(GRNDS2_DSTNC - GRNDS_DSTNC, lower=0)
       단, has_trans2=False 인 행은 NaN 처리
  └─ 히스토그램: 0~50km 범위, bins=20
```

| 컬럼 | 설명 |
|------|------|
| `GRNDS_DSTNC` | 1차 이송 거리(km) |
| `GRNDS2_DSTNC` | 2차 이송 거리(km) — 정상 이송에도 값이 있어 단독 판별 부적합 |

## 2. 소방서 출동 부하

### 2-1. 상위 30개 안전센터 막대 (`station_load_bar.png`)

```
[A] 구급출동 샘플 (120,000행)
  └─ 제외: CNTR_NM == "현장대응단" (약 27% — 실제 센터 아닌 출동 분류)
  └─ groupby(CNTR_NM).size()
       → 안전센터별 출동건수 집계
  └─ 상위 30개 수평 막대
```

---

### 2-2. 버블 지도 (`station_load_map.html`)

```
[A] 구급출동 샘플 (현장대응단 제외)
  └─ groupby(CNTR_NM).size() = 출동건수 DataFrame
  └─ 정규화 키: normalize_center_name(CNTR_NM)
       예) "역삼119안전센터" → "역삼"

[B] 소방서 좌표 (1,216행)
  └─ 정규화 키: normalize_center_name(기관명)
       예) "서울소방서-역삼-119 안전센터" → "역삼"

LEFT JOIN on 정규화키
  → 출동건수 + 위도·경도 결합
  → Folium CircleMarker (반지름 ∝ √출동건수)
  매칭률: 69.3% (101개 중 70개 좌표 확보)
```

> 미매칭 원인: 정규화 후에도 센터명 표기 차이  
> (예: `공단119안전센터` vs `(구)공단119안전센터`)

## 3. 증상 분석

### 3-1. 증상별 정상처리율 (`symptom_01_transport_rate.png`)

```
[A] 구급출동 샘플 (120,000행)
  └─ 파생컬럼: is_normal = (TRMN_SE_NM == "정상")
       ※ TRMN_SE_NM 실제 값: 정상(96%), 취소(2.9%), 오인(0.7%), 기타, 거짓
          "이송" 이라는 값은 존재하지 않음 — "정상"이 완료이송을 의미
  └─ groupby(PTN_SYM_SE_NM)
       → 증상별 정상처리율 = is_normal.sum() / count × 100
       필터: 증상별 샘플 30건 이상
```

---

### 3-2. 환자 발생 유형 파이차트 (`symptom_02_type_pie.png`)

```
[A] 구급출동 샘플 (120,000행)
  └─ PTN_OCRN_TYPE_NM.value_counts()
       질병외 60,305건(50.3%) / 질병 56,508건(47.1%) / 기타 3,187건(2.7%)
  └─ 파이차트 (범례에 건수 표시)
```

> 이 컬럼은 3개 카테고리만 존재해 막대차트 대신 파이차트로 교체.

---

### 3-3. 증상 × 중증도 히트맵 (`symptom_03_severity_heatmap.png`)

```
[C] 구급상황관리 샘플 (10,000행/년 × 5년 = 50,000행)
  └─ 결측 제거: MAIN_SYM_NM, SRIL_CLSF_NM 모두 유효한 행만
  └─ 상위 15개 주증상 필터
  └─ pivot: MAIN_SYM_NM(행) × SRIL_CLSF_NM(열) → count
  └─ 행 정규화: 각 증상별 중증도 비율(%) = 행값 / 행합계 × 100
  └─ seaborn heatmap (YlOrRd, annotated)
```

> [A]와 [C]는 **결합하지 않음** — 각각 독립적으로 분석.  
> [C]에는 병원 의료지도 정보(MDLCR_DSCSN_*)가 포함되어 있어 증상 중증도 파악에 특화.

### 4-2. 상관계수 막대 (`weather_02_correlation.png`)

```
[A] 구급출동 샘플 (120,000행)
  └─ 날씨 컬럼이 [A]에 내장됨 (별도 JOIN 없음)
       HR_UNIT_ARTMP : 기온(°C)
       HR_UNIT_RN    : 강수량(mm)
       HR_UNIT_WSPD  : 풍속(m/s)
       HR_UNIT_HUM   : 습도(%)
       HR_UNIT_SNWFL : 적설량(cm)
       HR_UNIT_VSDST : 가시거리(m)
  └─ 일별 집계: groupby(DCLR_YMD)
       → 일별 출동건수 + 날씨 변수 평균
       유효 날짜: 89일
  └─ Pearson 상관계수 (scipy.stats.pearsonr)
```

| 변수 | r | 해석 |
|------|---|------|
| 기온(°C) | +0.267 | 더울수록 출동 증가 (p=0.012) |
| 강수량(mm) | +0.128 | 약한 양의 상관 |
| 가시거리(m) | -0.104 | 약한 음의 상관 |
| 풍속·습도·적설 | ≈0 | 유의미하지 않음 |

## 5. 시계열 트렌드

### 5-1. 연도별 출동 건수 (`ts_01_yearly_dispatch.png`)

```
[A] 구급출동_YYYY.csv 파일 6개 (샘플 아닌 전체 파일)
  └─ 파일별 행수 카운트 (헤더 제외)
       2017: 544,765 / 2018: 562,801 / 2019: 536,795
       2020: 477,927 / 2021: 551,597 / 2022: 617,414
  └─ 막대 + 추세선 (np.polyfit degree=1)
```

> 샘플(20,000행/년)이 아닌 **전체 파일 행수**를 집계.  
> 2020년 감소는 COVID-19 영향으로 추정.

### 5-2. 서울 월별 출동 추이 (`ts_02_monthly_seoul.png`)

```
[D] 서울시 구급출동현황 Excel (2022~2024, 시트 3개)
  └─ 시트별 파싱: pd.ExcelFile → xl.parse(sheet)
       컬럼: 기관명, 1월, 2월, ..., 12월
  └─ 합계 행 선택: df.iloc[0]
       ← 첫 번째 행이 항상 "서울청" 전체 합계
       ← str.contains("계") 패턴은 구이름에 "계"가 포함된 행도 오매칭하여 사용 불가
  └─ 월별 값(1~12월) 추출 → 연도별 선 그래프
```

| 연도 | 최고 월 | 최고 건수 | 최저 월 |

| 2022 | 8월 | 3,781 | 1월(2,601) |
| 2023 | 7월 | 3,688 | 2월(2,691) |
| 2024 | 8월 | 3,560 | - |

## 데이터 결합 관계 요약

```
A (구급출동)  ──────────────────────────────────── 단일 테이블 분석
  │                                               뺑뺑이, 증상, 날씨, 시계열(ts_01)
  │
  ├── LEFT JOIN (정규화 센터명) ──────────────────  B (소방서 좌표)
  │         → station_load_map.html                위경도 버블 지도
  │
C (구급상황관리)  ──────────────────────────────── 단일 테이블 분석
  │                                               증상×중증도 히트맵
  │           (A와 직접 결합하지 않음)
  │
D (서울 Excel)  ─────────────────────────────────  단일 테이블 분석
                                                  서울 월별 시계열
```

## 샘플링 전략 및 한계

| 데이터 | 샘플링 방법 | 비율 | 한계 |
|--------|------------|------|------|
| [A] 구급출동 | 상위 20,000행/년 (`nrows`) | ~3.5% | CSV가 지역별 정렬 → 서울 편향 |
| [C] 구급상황관리 | 상위 10,000행/년 (`nrows`) | 가변 | 동일 편향 가능성 |
| [A] 지역분석용 | 전체 파일 2컬럼만 (`usecols`) | 100% | 처리 시간 10초 내외 |
| [D] 서울 Excel | 전체 (497행/시트) | 100% | 서울 한정 |
