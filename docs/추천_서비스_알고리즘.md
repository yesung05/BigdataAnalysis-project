# 응급실 추천 서비스 알고리즘 정리

## 개요

사용자의 위치(위도·경도)와 주요 증상을 입력받아, E-Gen 실시간 병상 정보를 조합해 최적의 응급실 TOP-5를 추천하는 서비스.

- **구현 파일**: `app/pages/9_추천_서비스.py`
- **핵심 로직**: `src/recommend/hospital.py`
- **외부 API**: NEMC Mediboard (서울 응급실 51개 실시간 병상)

---

## 추천 흐름

```
사용자 위치 + 증상 입력
        ↓
NEMC API 호출 (서울 전체 응급실 51개 한 번에 조회)
        ↓
각 병원에 대해 스코어 계산
        ↓
스코어 오름차순 정렬 → TOP-5 반환
        ↓ (API 실패 시)
정적 fallback: 거리 기반 추천
```

---

## 스코어 계산 공식

```
score = 거리(km) × 분류가중치 × 병상팩터 × 증상수용팩터
```

**스코어가 낮을수록 우선 추천.**

---

## 각 팩터 상세

### 1. 분류가중치 (`_CLASS_WEIGHT`)

응급의료법상 등급 체계를 기준으로 수동 설정한 값.

| 병원 분류 | 가중치 | 의미 |
|-----------|--------|------|
| 권역응급의료센터 | × 0.65 | 가장 우수한 인프라 → 거리 페널티 완화 |
| 지역응급의료센터 | × 0.80 | 중간 수준 |
| 지역응급의료기관 | × 1.00 | 기준값 (보정 없음) |

> **출처**: 응급의료법 등급 체계 참고 + 수동 설정 (데이터 분석 근거 없음)

---

### 2. 병상팩터 (`_bed_factor`)

증상에 해당하는 병상의 가용 수에 따라 패널티/보너스 부여.

| 가용 병상 수 | 팩터 | 해석 |
|-------------|------|------|
| 10개 초과 | × 0.60 | 여유 있음 → 우선 추천 |
| 5 ~ 10개 | × 0.75 | 보통 |
| 1 ~ 4개 | × 0.90 | 병상 부족 |
| 0개 (만실) | × 2.00 | 강한 패널티 |
| 정보 없음 | × 1.00 | 중립 |

> **출처**: 임계값(10, 5, 1)은 경험적 휴리스틱. 실측 데이터로 튜닝되지 않음.

```python
def _bed_factor(count: int | None) -> float:
    if count is None:  return 1.00
    if count > 10:     return 0.60
    if count >= 5:     return 0.75
    if count >= 1:     return 0.90
    return 2.00  # 만실
```

---

### 3. 증상수용팩터 (`_accept_factor`)

E-Gen API의 `unavailableMessages` 코드를 통해 해당 증상의 수용 여부 판단.

| 수용 여부 | 팩터 | 해석 |
|-----------|------|------|
| 수용 가능 | × 0.50 | 강력 우선 추천 |
| 수용 불가 | × 2.50 | 강한 패널티 |
| 정보 없음 | × 1.00 | 중립 |

> **출처**: API 반환값 존재 여부 기반 + 수동 설정. 불가 페널티(×2.50)가 가능 보너스(×0.50)보다 5배 강하게 설계.

```python
def _accept_factor(ok: bool | None) -> float:
    if ok is True:  return 0.50
    if ok is False: return 2.50
    return 1.00
```

## 증상별 병상 매핑 (`_SYMPTOM_PROFILE`)

증상마다 관련 병상 코드(E-Gen API 필드)와 중증질환 수용 코드를 매핑.

| 증상 | 병상 키 | 중증 여부 | 레이블 |
|------|---------|-----------|--------|
| 흉통 | hv2 | ✅ | 심근경색 재관류 |
| 심정지 | hvicc | ✅ | 심근경색 재관류 |
| 의식저하 | hvcc | ✅ | 뇌출혈·뇌경색 처치 |
| 뇌졸중 의심 | hvcc | ✅ | 뇌졸중 처치 |
| 호흡곤란 | hvicc | ❌ | 인공호흡기 필요 |
| 외상·골절 | hv9 | ✅ | 중증외상 수술 |
| 복통 | hvec | ❌ | 응급내시경·복부수술 |
| 화상 | hvec | ✅ | 중증화상 |
| 저혈당 | hvec | ❌ | 일반 |
| 소아 | hvncc | ❌ | 소아응급 |
| 토혈·혈변 | hvec | ❌ | 응급내시경 |

`critical: True`인 증상은 중증질환 수용 여부(오퍼레이션 2)를 추가로 조회.

## 이송 예상 시간

```python
est_min = max(1, round(dist_km / 40 * 60))
```

- **가정**: 평균 이동 속도 시속 40km
- 실제 교통 상황·야간·응급 출동 속도 등은 반영하지 않은 단순 추정값

## 소방 안전센터 추천 (`src/recommend/station.py`)

별도 알고리즘 없이 Haversine 거리 계산 후 오름차순 TOP-3 반환.

```
거리(km) = Haversine(사용자 좌표, 안전센터 좌표)
→ 거리 오름차순 정렬 → TOP-3
```

## 지도 마커 색상 기준

| 색상 | 조건 |
|------|------|
| 🟢 초록 | 증상 수용 가능 |
| 🟠 주황 | 병상 있음 (수용 정보 없음) |
| 🔴 진빨강 | 만실 또는 수용 불가 |
| ⚪ 회색 | 실시간 데이터 없음 (정적 fallback) |
| 🔵 파랑 | 내 위치 |
| 🔴 빨강 | 소방 안전센터 |
