## 1. 구급출동현황 (2017~2022) — `01_구급출동현황_EDA.ipynb`

### 📁 데이터 개요

| 항목 | 값 |
|------|-----|
| 파일 수 | 6개 (2017~2022) |
| 파일 크기 | 183~236 MB/개 |
| 컬럼 수 | 92개 |
| 분석 샘플 | 30,000건 (6년 × 5,000) |

### 🔴 결측값 현황 (주요)

시간 관련 컬럼(DCLR_TM, DSPT_TM, GRNDS_ARVL_TM 등 시분초 컬럼) **전체 100% 결측** — 날짜(YMD)는 존재하나 정확한 시각(HH:MM:SS)은 기록되지 않음.

> ⚠️ **시사점**: 출동→현장도착 응답시간 분(minute) 단위 분석 불가. 날짜 단위 비교만 가능.

```
LFDAU_NM          100.00%
DCLR_TM           100.00%   ← 신고 시각 전체 결측
DSPT_TM           100.00%   ← 출동 시각 전체 결측
GRNDS_ARVL_TM     100.00%   ← 현장도착 시각 전체 결측
PTN_CNTC_TM       100.00%   ← 환자접촉 시각 전체 결측
CBK_TM            100.00%   ← 복귀 시각 전체 결측
ANML_ETC_CLSF_NM   99.99%
```

### 📊 주요 분석 결과

#### 처리 결과 분류 (TRMN_SE_NM)
| 분류 | 건수 | 비율 |
|------|------|------|
| 이송 | 27,603 | **92.0%** |
| 기타 | 1,226 | 4.1% |
| 미이송 | 1,038 | 3.5% |
| 거절 | 126 | 0.4% |
| 기타 | 7 | 0.02% |

#### 🚑 구급차 뺑뺑이 분석 (핵심)
| 구분 | 건수 | 발생률 |
|------|------|------|
| 2차 이송 (1회 거부) | 57건 | **0.19%** |
| 3차 이송 (2회 이상 거부) | 10건 | 0.03% |

> 샘플 기준 수치이므로, 연 100만 건 규모 전체 모수 기준 시 **연 약 2,000건 이상** 2차 이송 발생 추정.
> 이송 거리 컬럼: `GRNDS_DSTNC`, `GRNDS2_DSTNC`, `GRNDS3_DSTNC` 모두 존재 → 거부 시 이동 거리 분석 가능.

#### 발생 유형 및 지역
- **최다 발생 유형**: 질병 (압도적 다수)
- **최다 출동 지역**: 서울특별시
- **요일/월 분포**: `DCLR_DOW`, `DCLR_MM` 컬럼 활용 가능

#### 날씨 데이터 (7개 컬럼 존재)
| 컬럼 | 내용 |
|------|------|
| HR_UNIT_ARTMP | 기온(°C) |
| HR_UNIT_RN | 강수량(mm) |
| HR_UNIT_WSPD | 풍속(m/s) |
| HR_UNIT_WNDRCT | 풍향 |
| HR_UNIT_HUM | 습도(%) |
| HR_UNIT_SNWFL | 적설량(cm) |
| HR_UNIT_VSDST | 가시거리(m) |

> 날씨와 출동 건수 상관 분석 기반 마련됨.

## 2. 구급상황관리현황 (2019~2023) — `02_구급상황관리현황_EDA.ipynb`

### 📁 데이터 개요

| 항목 | 값 |
|------|-----|
| 파일 수 | 5개 (2019~2023) |
| 파일 크기 | 222~296 MB/개 |
| 컬럼 수 | 26개 |
| 분석 샘플 | 25,000건 (5년 × 5,000) |

### 🔴 결측값 현황 (심각)

```
CNTR_NM (의료지도센터명)    19,200건 / 25,000 → 76.8%
SRIL_CLSF_NM (중증도)       18,249건           → 73.0%
MAIN_SYM_NM (주증상)        16,569건           → 66.3%
EMD_NM (읍면동)              6,899건            → 27.6%
SGG_NM (시군구)              6,808건            → 27.2%
CTPV_NM (시도)                  14건            →  0.1%
```

> ⚠️ **시사점**: 핵심 분석 컬럼(증상, 중증도, 센터명)의 결측률이 66~77%로 매우 높아, 정제 후 활용 가능 건은 약 25~35% 수준. 데이터 수집 체계 개선 필요.

| 보통 | 2,676 | 39.7% |
| 중증상 | 2,453 | 36.4% |
| 경증 | 924 | 13.7% |
| 비응급(이송) | 400 | 5.9% |
| 사망 | 298 | 4.4% |

#### 의료지도 소요시간
| 통계 | 값 |
|------|-----|
| 유효 건수 | 24,749건 (98.9%) |
| 중앙값 | **1.9분** |
| 평균 | 2.9분 |
| 90th 백분위 | 5.7분 |

> 의료지도는 대부분 2분 이내 완료. 10% 케이스에서 6분 이상 소요.

| 복통 | 4 | 0 | 79 | 32 | 0 |

| 의식소실 | 36 | 1 | 6 | 95 | 1 |
| 호흡곤란 | 47 | 3 | 47 | 227 | 0 |

> - 두통·경련 → 중증상 비율 높음 (뇌졸중 등 의심)
> - 호흡정지 → 사망 비율 가장 높음 (20건)
> - 의식장애 → 경증 291건으로 이상치 (분류 기준 재검토 필요)

## 5. 종합 인사이트 및 다음 단계

### 핵심 발견사항

| 구분 | 발견 | 중요도 |
|------|------|--------|
| 뺑뺑이 | 샘플 기준 2차 이송 0.19% → 전체 모수 기준 연 수천 건 추정 | ⭐⭐⭐ |
| 시간 결측 | 정확한 시각(HH:MM) 전부 결측 → 응답시간 분 단위 분석 불가 | ⭐⭐⭐ |
| 상황관리 결측 | 중증도·증상 컬럼 66~77% 결측 → 정제 필요 | ⭐⭐⭐ |
| 계절성 | 여름철 출동 집중 (7~8월 peak) | ⭐⭐ |
| 호흡정지 사망 | 호흡정지 환자 사망 비율 가장 높음 | ⭐⭐ |
| 소방서 분포 | 전국 1,216개 완전한 좌표 보유 → 커버리지 분석 가능 | ⭐⭐ |

### 권장 후속 분석

1. **뺑뺑이 심층 분석**: `TRANS2_RSN` / `TRANS3_RSN` 거부 이유 분류 → 병상 부족 vs. 거리 vs. 전문성 비율 파악
2. **지역별 뺑뺑이**: 시도·시군구별 2차 이송 발생률 비교 지도 시각화
3. **날씨-출동 상관**: 기온·적설량과 구급 출동 건수 상관계수 계산
4. **응답시간 대안**: TM 컬럼 결측이므로, YMD 기준 **일별 출동 건수** 분석으로 전환
5. **상황관리 데이터 정제**: 결측 원인 파악 후 활용 가능한 25~35% 데이터로 증상 분석
