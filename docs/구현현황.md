## 전체 페이지 구성 (발표 스토리 순)

```
Home.py          → 소개: 왜 이 분석을 했나
1_데이터_현황.py  → 어떤 데이터를 사용했나
2_출동_트렌드.py  → 서울 구급 수요가 늘고 있다
3_뺑뺑이_분석.py  → 핵심 문제: 2차 이송이 증가 중
4_응급실_상관.py  → 원인: 응급실 접근성과 상관관계
5_소방서_현황.py  → 출동 부하가 특정 센터에 집중
6_증상_분석.py   → 어떤 환자가 어떤 결과를 맞나
7_날씨_상관.py   → 추가 요인: 날씨도 영향을 준다
8_신고유형_추세.py → 119 신고 유형 변화 (2011–2023)
9_추천_서비스.py  → 결론: 내 위치 기반 최적 소방서·병원 안내
10_AI_챗봇.py   → 분석 결과를 AI로 질의응답
```
