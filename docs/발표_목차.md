## 슬라이드 5 — 모델 · 특성 · 성능 (1분)

**핵심 메시지**: "ML 모델 대신 3가지 방법을 조합했습니다. 이유는 레이블이 없기 때문입니다."

**슬라이드에 넣을 것**

**새로 만든 특성 (핵심 3개만)**
- 2차 이송 발생률 = `TRANS2_RSN` 비null 비율
- 추천 스코어 = 거리 × 분류가중치 × 병상팩터 × 증상수용팩터
- ASOS 일별 집계 = 시간별 → 일별 평균/합계

**방법 선택 이유**

| 방법 | 이유 |
|------|------|
| 휴리스틱 스코어링 | 이송 목적지 레이블 없음 → 지도학습 불가 |
| Pearson 상관 | 가설 검증(날씨·응급실수) — 해석 가능성 우선 |
| GPT-4o Tool Calling | 정적 요약 주입 대비 14개 도구로 정확한 수치 직접 조회 |

**성능 지표**
- 날씨 상관 4개 변수 모두 p < 0.05 (1,459일)
- 병상 0개 병원 항상 하위 랭킹, 증상 거부 병원 2.5× 패널티 정상 작동
