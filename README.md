# 서울시 구급차 뺑뺑이 실태 분석

> 구급 출동·상황관리 빅데이터로 서울시 응급환자 이송 지연 실태를 분석하고  
> Streamlit 대시보드와 GPT 챗봇으로 시각화하는 프로젝트

**20241519 조예성** | 빅데이터분석프로젝트 | 2026

---

## 프로젝트 소개

구급차가 병원 수용 거절로 여러 병원을 전전하는 **'구급차 뺑뺑이'** 현상은  
응급환자의 골든타임을 위협하는 심각한 사회 문제입니다.

소방청 구급출동 원시 데이터(2017–2022)와 구급상황관리 데이터(2019–2023)를  
결합·분석하여 지연 실태를 정량화하고, 지역·증상·시간대별 병목 원인을 규명합니다.

### 분석 목표

- 연도별 **2차·3차 이송(병원 거절) 발생률** 및 추이 분석
- **시군구별 출동 밀도 지도**와 응급실 병상 현황 중첩 시각화
- 가장 빈도 높은 **구급 신고 증상** 분석 → 의료시설 확충 근거 도출
- OpenAI GPT 기반 **대화형 챗봇**으로 분석 결과를 일반인에게 쉽게 전달

## 시작하기

### 1. 저장소 클론

```bash
git clone <repo-url>
cd BigdataAnalysis-project
```

### 2. 가상환경 생성 및 패키지 설치

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. 환경변수 설정

```powershell
copy .env.example .env
# .env 파일을 열어 OPENAI_API_KEY 입력
```

### 4. 데이터 배치

`data/` 폴더 구조에 맞게 원본 파일을 직접 넣어주세요.

```
data/
├── 구급출동현황/
│   ├── 구급출동_2017.csv
│   └── ... (2018–2022)
├── 구급상황관리현황/
│   ├── 구급상황관리 현황_2019_전국.csv
│   └── ... (2020–2023)
├── 서울시 소방 구급 출동 현황(2022_2024).xlsx
├── 소방청_119신고 전화 유형_20231231.csv
└── 소방청_서울특별시 주소별 구급출동현황_20191231.csv
```

### 5. 대시보드 실행

```powershell
streamlit run app/Home.py
```
